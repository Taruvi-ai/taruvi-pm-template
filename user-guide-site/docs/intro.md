# Welcome to the Project Management User Guide

This guide is for people using the app day to day. It focuses on where to go, what each area is for, and how to keep work moving.

<img src="/user-guide/img/user-guide/dashboard.png" alt="Dashboard overview" />

## What this app helps you do

- Track the projects you can access.
- Focus on tasks assigned to you.
- Switch between list, board, gantt, and calendar views.
- Comment on work, attach files, and keep task details current.

## How to use this guide

- Start with [Navigation and Home](./navigation-and-home.md) if you are new to the app.
- Open [Projects and Views](./projects-and-views.md) when you need to create or manage project workspaces.
- Use [My Assignments](./my-assignments.md) if your main job is staying on top of your own task list.
- Visit [Calendar View](./calendar-view.md) when you need a timeline of upcoming work.
- Check [Task Details](./task-details.md) for comments, attachments, status changes, and due dates.

:::tip Getting started
If your screen looks mostly empty, that usually means you do not have active projects or assigned tasks yet. The guide still applies. The same controls appear once work is available.
:::
