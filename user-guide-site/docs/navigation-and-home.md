# Navigation and Home

The left navigation is your main way to move around the app. The Home dashboard is the quickest place to understand what needs attention.

<img src="/user-guide/img/user-guide/dashboard.png" alt="Dashboard overview" />

## What you can find in the main navigation

- `Dashboard` shows a high-level summary of projects, overdue work, upcoming tasks, and recent comments.
- `My Assignments` narrows the app down to tasks assigned to you.
- `Projects` shows every project you can access.
- `Calendar View` lays work out across time.

## When to use the dashboard

Open the dashboard when you want a quick answer to these questions:

- What is assigned to me right now?
- What is overdue?
- What is due soon?
- Are there recent comments I should read?

## Quick actions from Home

- Use `Add Task` to start a new task quickly.
- Select `Open My Assignments` to jump straight into your own work queue.
- Open counts such as `To Do`, `In Progress`, or `Done` to move into a filtered task view.

## Built-in help link

The app sidebar footer includes a `User Guide` link so you can open this guide without leaving your current workflow.
