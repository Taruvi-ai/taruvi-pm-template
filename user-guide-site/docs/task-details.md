# Task Details

Task details are where day-to-day updates happen. You will usually open a task from a list, board, gantt, dashboard card, or calendar entry.

## What you can do in a task

- Review the task name, description, status, and priority.
- Update progress and the current assignee.
- Check original and updated due dates.
- Upload supporting files.
- Add comments and review activity history.

:::note Assigning work
When creating or editing a task, you can assign it to a user who may not currently have access to the project through private, team, department, or observer rules. Assignment and project visibility can differ, so check both if someone is meant to work in the project and not just receive the task.
:::

## Comments and activity

Use comments to explain changes, share context, or ask follow-up questions. The activity section keeps a running record of what changed and when it changed.

## Attachments

Use file attachments for documents, screenshots, and other supporting material that belongs with the task.

## Statuses you will see most often

- `To Do` means the work has not started yet.
- `In Progress` means someone is actively working on it.
- `Review` means it needs checking or approval.
- `Done` means the work is complete.

## Keeping tasks healthy

- Update the status when work moves.
- Keep the due date realistic.
- Add a comment when a change needs explanation.
- Attach the files others will need later.

:::tip Good habit
If a task slips, update the date and leave a short comment at the same time. That keeps the timeline and the conversation aligned.
:::
